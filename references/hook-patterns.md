# 第一行写作模式

第一行是信息流中的首要战场。它必须让目标读者停下来，同时不能误导读者对正文价值的预期。

中文推文在内容允许时，把第一行控制在约 20 至 40 个汉字。直接呈现最强信息，不要在进入主题前预热。

## 目录

1. 反差型
2. 数字锚定型
3. 悬念型
4. 直接宣言型
5. 开头修改方法
6. 淘汰规则

## 1. 反差型

把一个常见认知和相反或意外的结论并列，制造认知冲突。

公式：

```text
[大多数人以为 A] + [但实际上 B]
```

适合原文中存在有依据的反直觉判断时使用。

示例形态：

```text
大多数人以为增长靠更多内容。实际上，冷启动首先取决于分发。
```

不要制造虚假二分。保留必要的条件和边界。

## 2. 数字锚定型

用真实数字让信息变得具体、可衡量，再留下一个有意义的待解问题。

公式：

```text
[具体数字] + [做了什么或发生了什么] + [尚未揭示的原因或经验]
```

适合真实结果、实验、时间线、数据分析和过程记录。

示例形态：

```text
我分析了 600 条推文，真正持续带来互动的只有 4 种开头。
```

禁止编造或装饰数字。不要把估算写成精确测量结果。

## 3. 悬念型

从一个重要事件、决定、失败或转折开始，但不立即揭示结果。

公式：

```text
[有冲击力的事件或决定] + [有依据的留白]
```

适合具有真实推进过程的故事。

示例形态：

```text
客户照着我的方法做了一个月，数据反而更差。我打开后台后发现了问题。
```

尽快兑现答案。不要用薄弱事实强行拉长悬念。

## 4. 直接宣言型

不用铺垫，直接给出一个短促、清晰、坚定的判断。

公式：

```text
[清晰且可辩护的判断]
```

适合观点、诊断、认知颠覆和强结论。

示例形态：

```text
你的内容没有问题。你的分发有问题。
```

只有证据足够支持确定性时，才删除“我觉得”“可能”“也许”等缓冲词。不要人为制造确定感。

## 5. 开头修改方法

开头较弱时：

1. 先写完完整推文。
2. 如果原第一行只是在介绍话题，直接删除。
3. 找出正文中最有冲击力且真实的一句话。
4. 把这句话移到最前面。
5. 使用四种模式之一重写。
6. 朗读一遍，检查它是否提供了一个诚实的继续阅读理由。

## 6. 淘汰规则

淘汰依赖以下手段的第一行：

- 没有依据的最高级或普遍化判断
- 虚假秘密、紧迫感或争议
- “一切都变了”等模糊表达
- 原文中不存在的数字
- 答案显而易见的问题
- 正文无法兑现的悬念
- 侮辱或羞辱读者
- 比正文价值更夸张的承诺
