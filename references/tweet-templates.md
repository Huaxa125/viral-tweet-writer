# 推文结构模板

把模板当作信息排列方式，不要把模板当作思考的替代品。选择适合原始内容的结构，完成初稿后，再消除明显的模板痕迹。

## 目录

1. 认知颠覆型
2. 个人经历拆解型
3. 框架输出型
4. 清单型
5. Before/After 型
6. 过程透明型
7. 对比分析型
8. 故事钩型
9. 教学实操型
10. 观点宣言型
11. 去除模板感

## 选择指南

| 原始内容 | 优先选择的模板 |
| --- | --- |
| 挑战常见认知 | 认知颠覆型 |
| 真实成功或失败经历 | 个人经历拆解型 |
| 原创判断模型 | 框架输出型 |
| 多项实用推荐 | 清单型 |
| 可以衡量的状态转变 | Before/After 型 |
| 正在进行的工作和真实数据 | 过程透明型 |
| 需要在两个选项之间做决定 | 对比分析型 |
| 有转折的真实事件 | 故事钩型 |
| 可以重复执行的方法 | 教学实操型 |
| 有边界的明确立场 | 观点宣言型 |

## 1. 认知颠覆型

适合作者不同意某个被广泛接受的观点，并且有依据支撑时使用。

```text
第一行：挑战一个常见认知
第二行：指出这个认知的问题
第三至五行：作者观点和论据，每段一个重点
最后一行：可以独立传播的结论
```

让结尾形成新的认知模型，不要只重复开头。

## 2. 个人经历拆解型

适合真实的成功、失败、实验或学习过程。

```text
第一行：把可衡量的结果放在前面
第二行：交代时间线或背景
第三至六行：关键动作或转折点，每行一个
最后一行：最重要的经验
```

只使用原文中真实存在的第一人称事实。如果失败过程能够解释结果，保留失败过程。

## 3. 框架输出型

适合作者把复杂问题压缩成实用思维模型时使用。

```text
第一行：读者可以对号入座的问题
第二行：框架名称或核心原则
第三至五行：三到五个组成部分，每个一句
最后一行：使用方式或适用边界
```

优先使用描述性名称，不要为了包装而创造夸张的框架名称。

## 4. 清单型

适合基于真实测试、筛选或经验得出的少量推荐。

```text
第一行：痛点加范围明确的承诺
后续各行：一个项目加一条理由，不要只列名称
最后一行：作者的个人推荐及原因
```

只有推文确实适合作为长期参考时，才加入收藏引导。

## 5. Before/After 型

适合原文包含可以归因到具体行为的状态变化时使用。

```text
第一行：Before 状态，使用数字或场景
第二行：After 状态，保持相同的具体程度
第三行：提出转折问题——中间发生了什么
第四至六行：具体改变的行为
最后一行：最反直觉的经验
```

如果原文只能证明相关性，不要擅自写成因果关系。

## 6. 过程透明型

适合正在进行的项目、实验、产品、学习或账号增长记录。

```text
第一行：正在做什么以及当前阶段
第二至四行：使用真实数字呈现进展
第五行：问题或意外发现
最后一行：下一步行动或准备验证的假设
```

真实的未达预期同样有价值。不要把每次更新都包装成成功。

## 7. 对比分析型

适合读者经常比较的两个工具、路径、策略或内容形式。

```text
第一行：提出两个选项和需要做的决定
第二至四行：每行比较一个维度
第五行：说明什么情况选择哪个
最后一行：给出限制条件或组合方式
```

如果答案取决于具体情况，不要宣布一个普遍适用的赢家。

## 8. 故事钩型

适合包含矛盾、转折和可迁移经验的真实经历。

```text
第一行：从关键时刻开始
第二至四行：每句话推动一次故事发展
第五行：结果或意外
最后一行：从故事中提炼出的具体认知
```

认知是故事的真正价值，悬念只是传递方式。

## 9. 教学实操型

适合读者看完后可以完成一项具体任务的内容。

```text
第一行：读者痛点加要教的事情
第二行：现实可达的预期结果
第三至六行：操作步骤，每行一个动作
最后一行：注意事项、检查标准或进阶提示
```

除非原文提供可靠证据，否则不要承诺具体的数字提升。

## 10. 观点宣言型

适合对有争议的话题表达明确立场。

```text
第一行：清晰表达立场
第二至四行：相互独立的支撑理由
第五行：承认观点不成立的条件
最后一行：在更深层次上强化立场
```

判断的锐度来自精确和有依据，而不是拒绝所有限定条件。

## 11. 去除模板感

完成初稿后：

1. 用原文中的真实数字、场景、决定或机制替换泛化表达。
2. 把判断强化到作者可以辩护的最精确版本。
3. 匹配作者平时使用的词汇、标点和节奏。
4. 删除只是因为模板预留了位置而出现的句子。
5. 进行换署名检验：如果任何人都可能写出这条推文，加入只有这位作者知道或能够得出的内容。
